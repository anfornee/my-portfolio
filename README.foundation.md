# Portfolio Foundation

This folder is a drop-in baseline for a fresh Vite + React + TypeScript project.

It intentionally adds no runtime dependencies.

## Install

Copy the contents into the root of the existing Vite project.

The bundle assumes the project already has the standard React/Vite dependencies.

## Run

```bash
npm install
npm run dev
```

Then verify:

```bash
npm run build
```

## What this baseline includes

- design tokens
- global accessibility defaults
- responsive sticky navigation
- large editorial hero
- ambient canvas particles
- animated SVG signal path
- reduced-motion handling
- two simple content sections to prove the layout system
- footer
- developer and coding-agent documentation
